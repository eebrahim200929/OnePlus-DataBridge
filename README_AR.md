# DataBridge — OnePlus 12 / OxygenOS 16

**هذا مشروع Android Studio وليس ملف APK جاهزًا. لم يتم بناؤه أو اختباره على الجهاز.**

## الفكرة
مستكشف ملفات عربي بسيط مخصص لـ `Android/data` و`Android/obb`، يستعمل واجهة Shizuku لإجراء عمليات القراءة بنظام صلاحيات `shell` عوض أن يطلب منك إذن نظام Android في كل مجلد. يعرض محتويات المجلدات، ويدعم نسخ الملفات **بدون حذف الأصل** إلى `Downloads`.

**قيد مهم:** لا يلغي رسالة `File system provider not found for` في التطبيقات الأخرى. ولا يستطيع تجاوز SELinux أو قيود وصول `shell` عند منعها من النظام؛ نجاحه على OnePlus 12/OxygenOS 16.0.10 غير مضمون.

## البناء
1. افتح المجلد في Android Studio مع JDK 17 و Android SDK API 35.
2. انتظر مزامنة Gradle (يحتاج إنترنت لتنزيل المكتبات).
3. نفّذ Build > Build Bundle(s) / APK(s) > Build APK(s).
4. سيتولد `app/build/outputs/apk/debug/app-debug.apk` (نسخة اختبار وموقعة بمفتاح Android Studio الافتراضي).

أو ارفع ملفات المشروع إلى مستودع GitHub وشغّل الإجراء `Build debug APK` من تبويب Actions لتحصل على ملف APK كـ Artifact.

## الاستخدام
1. ثبّت Shizuku من المصدر الرسمي: https://shizuku.rikka.app/download/
2. فعّل خيارات المطوّر ثم `Wireless debugging`، واربط Shizuku برمز الاقتران ثم شغّله.
3. ثبّت APK الناتج، واضغط «اتصال / منح إذن Shizuku» ووافق على الإذن.
4. ادخل إلى `Android/data`، واضغط على أي مجلد للتصفح. الضغط على ملف يتيح نسخه إلى `Downloads`.

## أمان وحدود
- لا توجد صلاحية شبكة في التطبيق، ولا مسح أو تغيير أو استبدال للملفات.
- الطلبات محصورة داخل Android/data و Android/obb.
- النسخ لا يستبدل ملفًا موجودًا بل ينشئ اسمًا جديدًا.
- يتم فصل Shizuku عن التطبيق إذا توقفت خدمته وقد تحتاج إعادة تشغيله بعد إعادة تشغيل الجوال.
- لا تضع ملفات حساسة في `Downloads` إذا كان بإمكان تطبيقات أخرى رؤيتها.

## لماذا ليس APK مباشرًا؟
بيئة إنشاء هذا المشروع لم تحتوِ على Android SDK أو أدوات التحزيم والتوقيع، ولم تسمح بتنزيل حزمها؛ لذلك لم أدّع وجود APK تم اختباره.
